# Codon Table Generator

## Project Description
This Python project translates DNA and RNA sequences
into their corresponding amino acids using the standard
genetic code.

## Features
- Stores all 64 codons in a Python dictionary.
- Accepts DNA and RNA sequences.
- Validates nucleotide sequences.
- Splits sequences into groups of three nucleotides.
- Identifies start and stop codons.
- Handles incomplete codons.
- Displays the complete codon table.
- Displays the translated amino acid sequence.

## Technologies Used
- Python
- Visual Studio Code
- Git
- GitHub

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

   python codon_table_generator.py

5. Enter a DNA or RNA sequence when prompted.

## Sample Input
ATGGCTTTTTAA

## Expected Translation
Methionine - Alanine - Phenylalanine - Stop
